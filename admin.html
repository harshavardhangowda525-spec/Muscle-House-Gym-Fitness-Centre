Connect the database

The admin dashboard needs a free Supabase project. Until it's connected, the website shows "Enquire now" instead of online payment.

  1. Create a project at supabase.com.
  2. Open SQL Editor, paste the contents of supabase/schema.sql and run it.
  3. Under Authentication → Users, add the owner's email and password.
  4. Make that user an admin by running the snippet at the bottom of schema.sql with their email.
  5. Copy the Project URL and anon public key (Project Settings → API) into assets/js/config.js.

Full instructions are in the README.
